📖 How to obtain Razorpay API Keys (Step-by-Step Guide)
  1. Log in to your Razorpay Dashboard at https://dashboard.razorpay.com/.
  2. In the top bar, choose Test Mode (for sandbox testing) or complete KYC and switch to Live Mode.
  3. Navigate to Account & Settings → API Keys.
  4. Click Generate Key (or Regenerate Key) to generate your Key ID and Key Secret.
  5. Copy the Key ID (starts with rzp_test_... or rzp_live_...) and Key Secret, paste them in the fields above, and click Save.
  6. Click Test Connection to verify live authentication with the Razorpay API.
  7. (Optional Webhook) Under Webhooks, add URL: http://your-domain.com/api/payment/webhook and subscribe to payment.captured, payment.failed, refund.processed.
